# Competitor: Visible.vc
Category: Holding-company / portfolio operator tool
URL: https://visible.vc/

## What They Do
Visible is a portfolio monitoring and investor relationship platform built for venture capital funds. It automates data collection from portfolio companies (parsing emails, PDFs, and structured requests), consolidates KPIs into dashboards, and generates LP-ready tear sheets and reports. Trusted by 950+ venture funds globally, it positions itself as a "portfolio monitoring platform built for the AI era."

## Target User
VC fund managers, family offices, and institutional investors who manage portfolios of 10-200+ companies and need to collect standardized metrics, track performance, and report to LPs/stakeholders.

## Key Features
- Automated data collection from portfolio companies via email parsing, PDF extraction, and structured survey requests
- Centralized KPI dashboards with portfolio-wide and per-company views
- LP reporting with customizable tear sheet templates (PDF, email, and link distribution)
- Performance threshold alerts — set targets on tracked metrics and get notified on breaches
- AI-powered portfolio intelligence that extracts metrics and narratives from unstructured data
- MCP server integration — connects portfolio data to LLMs and external AI agents for custom workflows
- Data export to Google Sheets, Excel, and data warehouses
- Fundraising CRM and pitch deck hosting with per-slide analytics (founder-facing product)
- SOC 2 certified with TLS 1.2 and AES-256 encryption

## Pricing
- **Founder plans**: Free tier available; paid plans at $59/mo (Base), $129/mo (Core), $199/mo (Growth)
- **Investor/VC plans**: Custom pricing, reportedly starting around $2,000-3,000/month for smaller funds, scaling with portfolio size

## Strengths (vs Foundry)
- Deep VC/LP ecosystem fit — purpose-built for the investor-founder reporting relationship
- Massive adoption (950+ funds) creates network effects and industry-standard status
- MCP server is forward-looking — lets customers plug Visible data into their own AI agents
- Lightweight for portfolio companies — founders send updates via email, not a new platform
- SOC 2 certification and enterprise-grade security already in place

## Weaknesses (vs Foundry)
- Passive monitoring, not autonomous action — Visible collects and displays data but does not execute decisions or take action on behalf of the operator
- No multi-company operational control — cannot manage billing, deploy code, handle customer support, or run operations across portfolio companies
- VC-centric design — optimized for investor-founder reporting, not for a hands-on operator who runs the companies themselves
- No agent architecture — the MCP server exposes data but Visible itself does not run autonomous agents; the operator must build their own AI workflows
- Single-axis intelligence — focused on financial KPIs and metrics, not cross-functional (engineering, support, sales, legal) operational awareness

## Key Insight
Visible proves there is strong demand for centralized portfolio intelligence, but it stops at the "observe and report" layer. Foundry's opportunity is to start where Visible ends: not just monitoring KPIs but autonomously acting on them across every function of every company in the portfolio. Visible's MCP server also signals that the market expects AI-agent interoperability — Foundry should ensure its agent outputs are consumable by tools like Visible that LPs already use.
