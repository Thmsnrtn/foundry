# Owner OS visual reconstruction

Status: active UI implementation branch. No deployment requested.

## Boundary

This tranche changes owner-facing presentation and information hierarchy only. Canonical institutional state, authority, money, evidence, experiment semantics, and external-effect boundaries remain unchanged.

## Visual doctrine

- Private economic institution viewed from the owner chair, not generic SaaS.
- Dark charcoal / forest ground; restrained mint for state and direction; warm gold only for owner consequence and attention.
- Editorial serif for the sentence or number that matters; operational sans for everything else.
- Desktop uses width as information space. Mobile remains calm, thumb-safe and honest at 200% text.
- Unknown is rendered as unknown, never as zero.
- Motion is causal only; quiet state remains visually quiet.
- No global autonomy score, AI-thinking theater, activity vanity metrics, or fabricated charts.
- One canonical stylesheet after cutover. No permanent overlay layer.

## Surfaces in the reconstruction

Home / Founder Cockpit; Decisions; Experiments; Portfolio and River; company overview and honest trends; Money; Roadmap; Activity; Controls / Authority; Absence.

## Current proof discipline

The reconstruction preserves the existing phone-overflow invariant, one-stylesheet vocabulary, journey rehearsal, light-mode and reduced-motion rules. Deeper surface changes must be verified by targeted checks before they are committed.

## External boundary

No deploy, account creation, payment setup, listing publication, outreach, spending, or other external effect is part of this UI tranche.
