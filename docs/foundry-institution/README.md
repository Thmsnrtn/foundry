# Foundry Institution

This directory is the durable V1→V8+ governing context for Foundry's evolution from an agent-centric SaaS into an **Adaptive Company Institution**: a system capable of discovering, understanding, and progressively operating unfamiliar companies.

Read in this order:

1. [`CONSTITUTION.md`](CONSTITUTION.md) — non-negotiable laws and boundaries.
2. [`ARCHITECTURE.md`](ARCHITECTURE.md) — canonical institutional flow and migration rules.
3. [`EXPERIENCE.md`](EXPERIENCE.md) — founder-facing information architecture and governance language.
4. [`ECONOMICS.md`](ECONOMICS.md) — value, cognition-routing, and attention discipline.
5. [`PROOF_PROGRAM.md`](PROOF_PROGRAM.md) — evidence maturity, proof debt, and delivery method.
6. [`IMPLEMENTATION_STATE.md`](IMPLEMENTATION_STATE.md) — live baseline, verified findings, unknowns, and tranche state.

These documents govern future implementation. Existing code and older design documents describe implementation history; they do not override this institution. Update `IMPLEMENTATION_STATE.md` when evidence changes. Amend the other documents deliberately when the governing theory changes, never merely to rationalize current code.
