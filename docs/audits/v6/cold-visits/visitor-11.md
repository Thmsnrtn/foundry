The Ledger agent does "revenue tracking, financial health, ROI" but I need AP/AR, cash flow forecasting, multi-entity consolidation, budget variance analysis. This appears to be a surface-level financial view embedded in a broader operations tool. The Investor-Ready tier mentions "board packets" and "funding readiness score across 7 dimensions" which sounds like investor relations, not financial management.
