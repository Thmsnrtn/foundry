# Rescore 11 — PE Fund Operations Analyst

**Profile:** Works at a PE fund managing 20+ portfolio companies. Responsible for operational improvement across the portfolio. Evaluates tools for portfolio-wide deployment.

**Category ID (5/5):** "The Operating System for Portfolio Founders" — the word "portfolio" is in the eyebrow. "One control plane for all your companies" is exactly the pitch I'd make to my partners. The "Portfolio operators & studios" card at 15+ companies with "fleet-wide intelligence" is my use case verbatim.

**Value Prop (4/5):** Cross-portfolio pattern detection is the holy grail for PE ops. The briefing example showing a shared onboarding fix across companies is the kind of insight we pay consultants $50K to find. The agent architecture (12 per company, centralized intelligence) mirrors how we think about portfolio operations.

**Pricing (3/5):** $399 for 5 companies. We manage 20+. There's no enterprise tier, no volume pricing, no "contact sales." For PE fund deployment, I need a conversation about custom pricing, data isolation, and SSO. The pricing page as-is is a dead end for my use case.

**Signup Readiness (2/5):** I can't self-serve into this. I'd need enterprise pricing, SOC 2 documentation, data isolation guarantees, and a demo. I'd email the team, but there's no "contact sales" CTA — just "Get Started" which implies self-serve signup. That's a missing path for enterprise buyers.

**First-Run Mental Model (3/5):** The product model is clear (companies + agents + briefings). But the onboarding assumes I'm the founder connecting my own GitHub. In PE ops, I'd be deploying this across portfolio companies run by other people. The deployment model isn't addressed.

**Frame Alignment:** YES — Perfect category match: "operating system for portfolio operators." The frame is exactly right, even if the go-to-market path for enterprise buyers is absent.

**Key Quote:** "The positioning is perfect for us. The product-market fit is there. But I need an enterprise door, not a self-serve signup button."
