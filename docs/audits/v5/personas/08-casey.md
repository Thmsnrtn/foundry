# Persona 08 — Casey

## Identity

- **Role:** Evaluator for team adoption
- **Background:** VP of Engineering at a startup studio that launches 3-4 new products per year. Tasked with evaluating Foundry for company-wide adoption. Will be spending the company's money, not their own, so the bar is institutional — ROI justification, security review, team onboarding friction, and admin controls all matter. Needs to present a recommendation to the CTO within two weeks.
- **Current situation:** Casey created a trial account and added one of the studio's existing products as a test. Is evaluating onboarding friction, agent output quality, multi-seat support, SSO compatibility, and whether the pricing model works for a studio that spins up and retires products frequently.

## Profile

| Attribute | Value |
|-----------|-------|
| Technical comfort | 7/10 |
| Fleet size | 1 (testing), would scale to 8-12 |
| Trust in autonomy | N/A — evaluating, not operating |
| Subscription tier | Solo trial (evaluating Growth or Investor-Ready) |

## Abandonment Triggers

1. No multi-seat support — cannot invite team members with scoped permissions.
2. Pricing penalizes product churn — adding/removing companies should not incur sunk costs.
3. No admin console, usage analytics, or team activity overview for the person paying the bill.

## Voice

> "I'm spending someone else's budget. I need to show them exactly what they're getting per dollar per company."

> "Can I invite my CTO to see this without giving them billing access? If not, that's a blocker."

> "We spin up and kill products quarterly. If retiring a company from Foundry is painful, we'll never adopt."
