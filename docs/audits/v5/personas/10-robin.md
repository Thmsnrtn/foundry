# Persona 10 — Robin

## Identity

- **Role:** Frustrated user about to churn
- **Background:** Ran a B2B SaaS product for 18 months using Foundry. Initially enthusiastic — the audit and remediation pipeline saved real time. But over the past three months, agent recommendations became repetitive, the decision queue felt like busywork, and two billing issues went unresolved for weeks. Robin has already exported most data manually and is looking for the cleanest possible exit.
- **Current situation:** Robin wants to delete the company from Foundry, cancel the subscription, and ensure no data is retained. Has concerns about whether agent-generated PRs will remain in the GitHub repo after departure, whether Foundry retains any proprietary data, and whether the exit process is reversible if Robin changes their mind within 30 days.

## Profile

| Attribute | Value |
|-----------|-------|
| Technical comfort | 6/10 |
| Fleet size | 1 company (down from 2 — already removed one) |
| Trust in autonomy | Zero — agents are part of the problem now |
| Subscription tier | Growth ($199), cancelling |

## Abandonment Triggers

1. Cannot find the cancellation/deletion flow within 30 seconds of looking.
2. Deletion is "soft" (data hidden but retained) without clear disclosure.
3. No confirmation of what happens to agent-generated artifacts (PRs, commits, branches) post-deletion.

## Voice

> "I'm leaving. Make it easy, make it clean, and tell me exactly what you're keeping."

> "If I have to email support to delete my account, you've already lost the exit interview too."

> "I want a receipt that says 'all data deleted' with a timestamp. Not a vague 'your data will be removed in 30 days.'"
