# Persona 01 — Alex

## Identity

- **Role:** Solo founder, pre-revenue SaaS
- **Background:** Former backend engineer at a mid-stage startup. Left to build a niche vertical SaaS for property-management accounting. Has strong technical skills but zero experience running a business end-to-end. First time managing billing, compliance, marketing, and ops simultaneously.
- **Current situation:** Just launched a landing page and has ~20 beta users. Drowning in the gap between "I can write code" and "I need to run a company." Has heard about Foundry from a founder Slack community and is evaluating whether autonomous agents can close the knowledge gap.

## Profile

| Attribute | Value |
|-----------|-------|
| Technical comfort | 8/10 |
| Fleet size | 0 → 1 (onboarding first company) |
| Trust in autonomy | Low — needs to see agents earn trust before delegating |
| Subscription tier | Solo ($79) |

## Abandonment Triggers

1. Onboarding takes more than 10 minutes or requires information Alex does not have on hand.
2. The first SCP briefing is generic boilerplate that does not reference Alex's actual repo/stack.
3. Agent recommendations feel like a chatbot summarizing docs rather than reasoning about the business.

## Voice

> "I don't need another dashboard. I need something that actually understands my codebase and tells me what to fix first."

> "If I have to babysit the AI the same way I'd babysit a junior dev, what's the point?"

> "Show me one thing the agents found that I wouldn't have caught myself in the next week. That's the bar."
