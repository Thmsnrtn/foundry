# Persona 03 — Sam

## Identity

- **Role:** Portfolio operator, 5 companies
- **Background:** Serial entrepreneur who has built, scaled, and exited two SaaS companies. Currently running five products across different verticals — three generating revenue, one in beta, one winding down. Expects dashboards to reflect reality within minutes, not hours. Has strong opinions about data integrity.
- **Current situation:** Sam uses Foundry as the single source of truth for all five companies. Runs a weekly review ritual every Monday morning using the fleet dashboard. Gets frustrated when agent scores lag behind actual metrics or when cross-company comparisons are inconsistent.

## Profile

| Attribute | Value |
|-----------|-------|
| Technical comfort | 7/10 |
| Fleet size | 5 companies |
| Trust in autonomy | High for operational tasks, low for strategic decisions |

## Abandonment Triggers

1. Dashboard data is stale — scores updated hours ago when real metrics changed overnight.
2. Cross-company comparisons use different baselines or scoring periods without disclosure.
3. Cannot export fleet-level data for board presentations or investor updates.

## Voice

> "If the dashboard says Company C is green and I find out it missed payroll processing last night, we have a trust problem I can't recover from."

> "I run five companies. I need the fleet view to be a triage tool, not a gallery of pretty charts."

> "Show me the deltas since last Monday. Everything else is noise."
