# Run 081 — Taylor (P07) x Cross-Company Intelligence (J06)

**Persona:** Taylor — returning user after 6-week absence, Growth tier, 1 company
**Journey:** Cross-company intelligence investigation
**Severity Baseline:** Taylor needs to rapidly reconstruct what happened during absence.

---

## Precondition Check

Taylor has 1 company on Growth tier. Journey 06 requires 3+ companies. **BLOCKER: Fleet size = 1.**

This run inherits the same architectural gap identified in Run 076 — cross-company intelligence does not exist. However, Taylor's unique angle is: even if Taylor had multiple companies, after 6 weeks away, cross-company intelligence would be the most valuable view to return to. The absence makes the gap more painful.

---

## Simulation Transcript

### Step 1: Taylor logs in after 42 days

Taylor hits `/dashboard`. The dashboard shows:
- Signal score (current snapshot, no absence context)
- CEO Briefing (latest only, today's date)
- Stressor report (current active stressors)
- Decision count badge
- Query bar

**SPECIAL ATTENTION FINDING: What does the dashboard show Taylor after 6 weeks?**

The dashboard shows the **current state** only. There is no:
- "Welcome back" acknowledgment
- Catch-up summary covering the absence period
- Comparison of "Signal 42 days ago vs. today"
- Timeline of significant events during absence
- Agent lifecycle stage changes during absence

**Codebase evidence:** `src/routes/dashboard/index.ts` lines 141-155 — the dashboard fetches `computeSignal`, `getActiveStressors`, `getSignalHistory(60)`, `getDailyInsight`, `getPreviousSignalScore`, and `getLatestBriefing`. None of these are absence-aware. `getPreviousSignalScore` gets yesterday's score, not the score from 42 days ago.

### Step 2: Taylor sees the decision queue

The nav badge shows 23 pending decisions. Taylor clicks through to `/decisions`. All 23 are listed in reverse chronological order with no prioritization beyond date.

**No triage assistance.** Journey says "Decision queue shows 23 items with no prioritization — everything looks equally urgent." This is exactly what happens. The decisions page has no priority sorting, no "these 5 matter most" summary, no "these 12 can be safely bulk-dismissed" option.

### Step 3: Taylor checks the signal sparkline

The 60-day signal history sparkline shows the trend covering Taylor's entire absence. This is actually useful — Taylor can see if the score dropped, recovered, or stayed stable. But the sparkline is tiny (120x28px) with no annotation, no date labels, and no drill-down capability.

### Step 4: Taylor looks for cross-company insights

Not applicable — Taylor has 1 company and the feature does not exist. Same findings as Run 076.

## Findings

| # | Severity | Finding |
|---|----------|---------|
| 1 | CRITICAL | **No catch-up or re-engagement experience.** Taylor returns after 42 days and sees the exact same dashboard as a daily user. No absence detection, no summary digest, no "here's what happened while you were away." |
| 2 | CRITICAL | **Decision queue has no prioritization.** 23 pending decisions are listed chronologically with no urgency ranking, no "dismiss stale" bulk action, no AI-generated triage summary. Taylor must click into each one individually. |
| 3 | HIGH | **No agent activity summary for absence period.** Taylor cannot tell which agent actions during absence were beneficial vs. harmful without reading each signal individually. The CEO Briefing shows only the latest day's briefing. |
| 4 | HIGH | **Signal delta shows only yesterday, not absence start.** The `previousSignalScore` is yesterday's score. After 42 days away, Taylor needs "Signal was 71 when you left, now it's 58 — here's why." |
| 5 | CRITICAL | **Cross-company intelligence does not exist** (same as Run 076). |
| 6 | MEDIUM | **Signal sparkline is too small to be actionable.** 120x28px with no date annotations, no click-to-expand, no "what happened on this dip" drill-down. |

## Cross-Company Awareness Check

Not applicable — single company. But even at fleet scale, there is no absence-aware cross-company summary that would say "Company A's Signal dropped 20 points while Company B remained stable — here's the divergence."

## Verdict: JOURNEY BLOCKED (fleet size) + CRITICAL UX gap for returning users
