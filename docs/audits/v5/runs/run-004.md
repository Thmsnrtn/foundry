6. **Alex resolves the decision** → Enters chosen option and reasoning. Clicks "Resolve decision." → Success. Redirects back to queue.

8. **Alex returns to dashboard** → Signal score hasn't changed yet (computed on next cycle). Stressor section shows 1 active stressor (dependency vulnerability). → Alex clicks through to audit to investigate.
