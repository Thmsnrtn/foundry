# Run 091 — Devon (P09) x Cross-Company Intelligence (J06)

**Persona:** Devon — blind founder, screen reader + keyboard user, Growth tier, 3 companies
**Journey:** Cross-company intelligence investigation
**Severity Baseline:** Devon navigates entirely via keyboard/screen reader. Inaccessible features do not exist to Devon.

---

## Precondition Check

Devon has 3 companies on Growth tier. Journey 06 requires 3+ companies. Fleet size requirement is met. However, the core finding from Runs 076/081/086 applies: cross-company intelligence does not exist.

Devon's unique angle: even the non-existent feature would need to be accessible. But Devon can test the product switcher and multi-product navigation for accessibility.

---

## Simulation Transcript

### Step 1: Devon navigates to the dashboard via screen reader

Devon uses VoiceOver (macOS). The page loads. VoiceOver announces:
- "Skip to main content, link" (skip link exists in `src/views/layout.ts` line 74 -- good)
- Navigation landmarks: the sidebar has links but no `nav` landmark wrapping them in the dashboard layout

**Codebase evidence:** `src/views/layout.ts` — the sidebar is a `<div class="sidebar">` with `<nav class="sidebar-nav">` inside. The nav landmark exists. Good.

### Step 2: Devon uses the product switcher

Devon has 3 products. The product switcher is a `<select>` element in the layout. Devon tabs to it, hears the current product name, and can switch products.

**Codebase evidence:** The product switcher is rendered in the layout header. It uses a `<form>` with `<select>` and auto-submit on change. Screen readers can navigate `<select>` elements natively.

However: the `onchange` handler submits the form, which causes a full page reload. If Devon accidentally scrolls through options, each selection triggers a page reload. This is hostile to screen reader users who explore `<select>` options with arrow keys.

### Step 3: Devon looks for fleet intelligence

Devon navigates the sidebar. The links are:
- Dashboard, Agents, Decisions, Audit, Revenue, etc.
- No "Fleet" or "Cross-Company" or "Intelligence" link

Devon uses the command palette (Cmd+K). The command palette has `role="dialog"`, `aria-label="Command palette"`, and the input has `aria-label="Search pages and actions"`. Good ARIA on the palette.

Devon types "fleet" — no results. Types "cross" — no results. Types "portfolio" — may find the portfolio link.

### Step 4: Devon navigates to portfolio

Devon goes to `/portfolio`. This is the investor-layer portfolio view. It shows aggregated metrics across products but does not provide cross-company intelligence (same as Run 076).

**Accessibility of portfolio page:** Not audited in detail here, but the page would use the same component patterns as the rest of the dashboard.

## Findings

| # | Severity | Finding |
|---|----------|---------|
| 1 | CRITICAL | **Cross-company intelligence does not exist** (same as all J06 runs). |
| 2 | HIGH | **Product switcher auto-submits on change.** Screen reader users navigating `<select>` options with arrow keys trigger unintended page reloads. Should use a "Go" button or debounce. |
| 3 | MEDIUM | **Sidebar navigation is properly landmarked.** `<nav>` element wraps sidebar links. Skip link exists. Good. |
| 4 | MEDIUM | **Command palette has proper ARIA.** Dialog role, input label, and aria-controls are present. Good. |

## Cross-Company Awareness Check

Same as Run 076 — `decision_patterns` table has no access controls. Devon's 3 companies all contribute to and are influenced by the global pattern pool.

## Verdict: JOURNEY BLOCKED — Feature does not exist. Product switcher accessibility issue found.
