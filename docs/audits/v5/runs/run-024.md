## Step-by-Step

1. **Morgan logs in** → Dashboard loads. Signal: 71. Delta: +2. Sparkline shows 30-day trend. → Morgan taps the Signal number to open the Anatomy dialog.
2. **Signal Anatomy** → Base 85, stressor penalty -8, MRR penalty -6, backlog penalty 0, lifecycle bonus 0 = 71. Risk ceiling: no cap (green). → Morgan immediately questions: "Stressor penalty -8. Which stressors? How is -8 derived from the active stressors?"
3. **Morgan checks stressors** → Scrolls down. Stressor report shows 2 active stressors with severity levels. But the mapping from "2 stressors with severity critical + warning" to "-8 penalty" is not shown anywhere. → "The anatomy shows the penalty but not how the penalty was calculated from the stressor inputs."
4. **Morgan reads the CEO Briefing** → Navigates to `/agents/briefings/latest`. Briefing shows: agent contributions from Atlas (code quality), Oracle (retention analysis), Harbor (customer health). Financial summary. Pending decisions. → "Where are the citations? Atlas says 'dependency vulnerability detected in express@4.18.2.' Okay, I can verify that. But Oracle says 'retention improved 0.4%' — what data source? Where's the raw metric?"
5. **Morgan checks Agent Transparency for Oracle** → `/agents/transparency`. Finds Oracle's latest run. Clicks detail. Sees: prompt (includes product context, metric data injected), response (the analysis), token counts, model (Sonnet), cost ($0.0032). → "The prompt includes the metric data that was available to Oracle. I can see the inputs. Good."
6. **Morgan navigates to Decision queue** → 1 pending decision from Beacon: publish a case study. Gate 1 (notify + override). Morgan reads the recommendation, options, and scenario models. → "The scenario models show best/base/stress cases. But the methodology isn't described. Are these Monte Carlo simulations? Heuristic guesses? The label says 'scenarios' but the implementation could be anything."
7. **Morgan checks the decision's pattern section** → "67% of similar decisions had positive outcomes at this stage." → "What's 'similar'? How many data points? What's the confidence interval? Showing 67% without sample size is misleading."
8. **Morgan resolves the decision** → Chooses to approve, adds reasoning. → Smooth flow.
9. **Total triage: ~15 minutes** → But Morgan spent most of the time auditing the system's reasoning, not triaging business issues. Single-company triage for a trusting user would be ~5 minutes.
