# Run 016 — Riley (15-Company Power User) on Journey 01 (Landing to First SCP)

## Conditions
Fleet size: 0 → 1
Tier: Investor-Ready ($399)
Device: MacBook Pro, Arc browser, keyboard-centric workflow
Network: Gigabit fiber

## Step-by-Step

1. **Riley lands on foundry.so** → Scans the page in 5 seconds. "12 AI agents, SCP, connect your product." Riley doesn't read the marketing copy — jumps straight to "Get Started."
2. **Clicks "Give my product a team →"** → Clerk signup via GitHub OAuth. Instant. → Redirects to onboarding.
3. **Onboarding step 1** → Riley clicks "Connect GitHub →" immediately. GitHub OAuth completes in seconds (already logged in). → Repo list loads.
4. **Selects first repo** → Riley picks the first of the 15 companies' repos. Clicks submit. → Product created.
5. **Competitors** → Riley types 2 competitors fast, tabs through fields. Submits with Enter key. → Works. Form submission via keyboard is functional.
6. **Audit** → Triggers audit. Waits. → **FRICTION**: Riley's patience threshold is ~5 seconds. The synchronous audit takes 30-60 seconds. Riley opens a new tab and checks Slack while waiting. Returns to find it redirected to dashboard.
7. **Dashboard** → Signal: 74. Riley immediately hits Cmd+K. → Command palette opens. Riley types "agents" → "Agent Roster" highlighted. Enter. → Agent roster loads. → "Okay, Cmd+K works. That's good."
8. **Riley checks Agent Transparency** → Via Cmd+K → "Transparency" → Enter. Page loads showing per-agent cost, latency, token usage, model selection. → "This is what I need. I can see exactly what each agent costs and does."
9. **Riley's immediate thought** → "Good for one product. Now I need to add 14 more. How fast can I do that?"

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **NO** — Single company at this point.

## Friction Events
- FRICTION-0049: HIGH — Audit latency exceeds Riley's 2-second threshold. Riley context-switches away during the wait, which means the "first impression" moment is lost.
- FRICTION-0050: LOW — Onboarding wizard doesn't support keyboard-only navigation for competitor entry. Tab order works but there's no "add another competitor" keyboard shortcut.

## Verdict: SUCCESS
## Would Recommend: Not Yet — "One product works fine. Show me it works at 15."
