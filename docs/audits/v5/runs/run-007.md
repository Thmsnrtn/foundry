# Run 007 — Jamie (Two-Product Founder) on Journey 02 (Adding Second Company)

## Conditions
Fleet size: 1 → 2
Tier: Growth ($199)
Device: iPad, Safari
Network: Home Wi-Fi

## Step-by-Step

1. **Jamie logs in** → Dashboard shows ScheduleWidget Signal score. Jamie has been using Foundry for a week and wants to add the analytics add-on product.
2. **Jamie goes to Settings** → Sees "Products" card: 1 product connected. "+ Add Product" button visible. → Clicks it.
3. **Redirects to `/onboarding`** → Same wizard as before. Jamie chooses the no-code path again. Enters: "InsightPulse", "https://insightpulse.io", "Other", "B2B SaaS".
4. **Product created successfully** → Growth tier allows up to 3 products. No tier gate hit. Competitors page → Jamie enters 1 competitor → Audit runs.
5. **Redirects to `/dashboard`** → Dashboard loads... but it shows ScheduleWidget, not InsightPulse. The cookie is still set to the first product. → **FRICTION**: Jamie just onboarded InsightPulse but lands on ScheduleWidget's dashboard. No indication the new product was added or where to find it.
6. **Jamie notices the product switcher** → In the header, there's now a dropdown (where it previously said "/ ScheduleWidget" as breadcrumb). Jamie clicks it and sees both products. Selects InsightPulse. → Dashboard reloads with InsightPulse's data.
7. **Jamie navigates to `/portfolio`** → Tier gate fires: Multi-Product requires Investor-Ready. Gate page: "Investor-Ready allows unlimited products with cross-portfolio intelligence." → Jamie can't see a fleet view.
8. **Jamie's reaction** → "I added my second product and... I just have a dropdown to switch between them? There's no side-by-side view? I can't tell which one needs attention without clicking into each one."
9. **Jamie tries the command palette (Cmd+K)** → Lists navigation options but nothing fleet-level. No "Compare products" or "Fleet overview" option.

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **YES** — After onboarding InsightPulse, Jamie was dropped back onto ScheduleWidget's dashboard with no indication of the switch. The product switcher dropdown is subtle (a `<select>` element in the header breadcrumb). Jamie could easily make decisions thinking they're on InsightPulse when they're on ScheduleWidget.

## Friction Events
- FRICTION-0015: CRITICAL — After adding a second product, the user is redirected to the dashboard showing the FIRST product (cookie-based). No confirmation, no "switch to new product" prompt. This is a boundary confusion vector.
- FRICTION-0016: HIGH — Portfolio/fleet view is gated to Investor-Ready ($399). Growth ($199) founders with 2-3 products have NO fleet overview. They must use the header dropdown to switch one-by-one.
- FRICTION-0017: MEDIUM — The product switcher is a raw `<select>` element. On iPad/Safari, it opens the native iOS picker. No visual indicator of which product has issues. Jamie's trigger #1: "Fleet view is visually identical to single-company view."
- FRICTION-0018: MEDIUM — Jamie's trigger #2 activated: the briefing uses terms like "remediation PR" without explanation. No glossary or tooltip.

## Verdict: SUCCESS (technically) but BOUNDARY_CONFUSION in practice
## Would Recommend: No — "I added my second product and honestly I can't tell what changed."
