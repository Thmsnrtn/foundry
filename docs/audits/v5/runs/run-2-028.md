## Step-by-Step (against current code)

1. Robin wants to leave Foundry but is exploring options. Has 1 company remaining (already deleted the other).
2. Robin navigates to Settings > Manage Company. Sees three options: Pause, Export, Delete.
3. Robin considers Pause: "Suspend all agent activity and data ingestion. Your data is preserved." This is less intimidating than immediate deletion.
4. Robin decides to pause first, export data, then delete later. Clicks Pause. Product paused.
5. Robin exports data in CSV format. Downloads successfully.
6. Robin returns later to delete. Navigates to Privacy & Data, clicks "Delete This Product". Modal: "Delete all data for [Robin's Product]?" Clear and specific.
7. Robin confirms deletion. 30-day grace period begins.
