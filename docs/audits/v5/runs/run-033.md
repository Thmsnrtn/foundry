| Axis | Value |

| Fleet size | F2 (2 companies) |

| A11Y | A11Y-OFF |
| Account | ACCT-EST (2+ weeks SCP data) |
| Tier | TIER-GROW ($199) |
| Error | ERR-NONE |

## Step-by-Step Transcript

1. Jamie opens Foundry on mobile (390x844). Logs in.
2. Dashboard redirects to `/portfolio` -> tier gate (multi_product requires Investor-Ready).
3. Gate page loads. On mobile, the gate page is a simple HTML page with full-width layout. Readable but frustrating.
4. Jamie navigates directly to `/settings`.
5. Settings page renders on mobile. On NET-SLOW (2 Mbps, 300ms), full page load takes ~3-4 seconds (server-rendered HTML with CSS/JS).
6. Jamie scrolls through the Settings page on mobile. The layout uses inline styles with `display:flex;gap:0.5rem;flex-wrap:wrap` which mostly works on mobile.
7. **Subscription section**: Shows "Current Plan: Growth" badge. "You have access to N features."
8. **Upgrade option**: Only "Upgrade to Investor Ready" button shown. No downgrade option back to Solo visible.
9. Jamie looks for per-company cost breakdown: "Am I paying $199 total or $199 per product?"
10. **FRICTION**: No per-company pricing information. The tier names (Solo/Growth/Investor-Ready) suggest flat pricing, not per-company. But the product description says "multi-company pricing." Jamie cannot determine the actual cost model.
11. Jamie taps "Manage Subscription" -> Stripe portal loads. On mobile + NET-SLOW, Stripe portal takes 5-7 seconds to load.
12. Stripe portal shows the subscription details including actual amount charged. Jamie can see it is $199/month flat.
13. Jamie returns to Settings. Wants to understand: "If I upgrade to Investor-Ready, is it $399 flat or $399 per company?"
14. **FRICTION**: No pricing comparison on the upgrade button. Just "Upgrade to Investor Ready" with no price shown.
15. Jamie checks Products section. Both products listed. The "+ Add Product" button is visible but Jamie is unsure if adding more products increases cost.
16. **FRICTION**: On mobile, the product list and subscription section are far apart (requires scrolling). Cannot see billing and products simultaneously.
17. Jamie scrolls to the Wisdom Network toggle and the Investor/Advisor Access section. These are single-product scoped but the UI does not indicate which product they affect.
18. The Share Link and Ingest URL sections reference `firstProduct` (line 51 in settings.ts) — always the first product, regardless of cookie selection.
19. **FRICTION**: Share Link and Ingest URL are always for the first product, not the currently selected product. If Jamie wants to generate a share link for the second product, there is no way to do so.

## Cross-Company Awareness Check

- **Settings page**: Shows all products in the Products list, but Subscription card is founder-level (correct).
- **Share Link / Ingest URL**: Always references `firstProduct` — **incorrect for multi-product founders**. Should reference the selected product.
- **No product indicator**: Settings page does not show which product is "active" for product-scoped sections.

## Friction Events

| # | Severity | Category | Description |
|---|----------|----------|-------------|
| F033-1 | HIGH | Missing Information | No per-company pricing breakdown. User cannot determine if pricing is flat or per-company. |
| F033-2 | HIGH | Boundary Confusion | Share Link and Ingest URL sections always reference the first product, not the currently selected one. Multi-product founders cannot manage these for non-primary products. |
| F033-3 | MEDIUM | Missing Feature | No downgrade option visible. Growth users cannot see how to downgrade to Solo. |
| F033-4 | MEDIUM | Mobile UX | Subscription and Products sections separated by scrolling on mobile. Cannot see both simultaneously. |
| F033-5 | LOW | Upgrade UX | Upgrade button shows no price. User must visit Stripe to understand the cost difference. |

## Verdict

**FAILED**

Jamie cannot understand the billing model, cannot manage per-product settings (share links, ingest URLs) for the second product, and the pricing transparency required by J08 is absent.

## Recommendation

1. Show pricing on upgrade buttons: "Upgrade to Investor-Ready — $399/mo".
2. Fix share link and ingest URL to use the selected product (cookie-based), not hardcoded first product.
3. Add a pricing FAQ or tooltip explaining flat vs. per-company pricing.
4. Add product-scoped settings sections that clearly indicate which product they affect.
