## Precondition Check

Alex has 1 company on the Solo tier. Journey J06 requires 3+ companies with active SCP. The journey is structurally impossible at F1.

## Step-by-Step Transcript

1. Alex logs in. Dashboard loads showing single-product Signal view.
2. Alex sees the product switcher in the header — but it contains only one product. No dropdown affordance visible (select element with one option).
3. Alex looks for a "Fleet Intelligence" or "Cross-Company" link in the sidebar navigation.
4. **No such link exists.** The sidebar nav contains: Dashboard, Audit, Decisions, Lifecycle, Digest, Signals, Agents, Settings. No fleet/portfolio/intelligence link.
5. Alex tries the command palette (Cmd+K). Types "fleet" — no results. Types "cross" ��� no results. Types "intelligence" — finds "Founder Decision Intelligence" which is a per-product feature.
6. Alex clicks "Founder Decision Intelligence" — this is `/founder/state`, a per-product behavioral state detector. Not cross-company intelligence.
7. Alex navigates to `/portfolio`. Route exists but requires `multi_product` tier gate. Alex is on Solo tier.
8. **Tier gate page renders.** Shows "Multi-Product" feature name, "Investor-Ready allows unlimited products with cross-portfolio intelligence."
9. Alex reads the gate page. Upgrade message is clear but does not explain what cross-company intelligence actually looks like.
10. Alex navigates to Settings to check upgrade options.
11. Settings page shows "Current Plan: Solo" with upgrade buttons. No preview of fleet intelligence features.
12. Alex decides this journey is not possible on Solo with 1 company.

## Cross-Company Awareness Check

- **Product switcher**: Shows only 1 product. No confusion possible — but also no value signal for fleet features.
- **Portfolio route**: Tier-gated. Gate page mentions "cross-portfolio intelligence" but provides no preview.
- **Data isolation**: N/A — only one company exists.

## Friction Events

| # | Severity | Category | Description |
|---|----------|----------|-------------|
| F026-1 | MEDIUM | Discovery | No sidebar link to fleet/portfolio features. User must guess the URL or find it via upgrade gate. |

## Verdict

**ABANDONED**

Alex cannot access cross-company intelligence because (a) only 1 company exists, (b) Solo tier blocks the portfolio route, and (c) there is no discoverability path for fleet features. The journey never begins.

## Recommendation

Add a fleet features preview in Settings or a sidebar CTA that explains what cross-company intelligence provides. The gate page should show a concrete example (mock data) of a cross-company insight, not just a text description.
