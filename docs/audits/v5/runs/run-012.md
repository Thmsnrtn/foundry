# Run 012 — Sam (5-Company Portfolio) on Journey 02 (Adding Second Company)

## Conditions
Fleet size: 1 → 2
Tier: Investor-Ready ($399)
Device: MacBook Pro, Firefox
Network: Office broadband

## Step-by-Step

1. **Sam logs in** → Dashboard for Company A. Sam goes to Settings → "+ Add Product".
2. **Onboarding flow for Company B** → GitHub connect → repo select → competitors → audit. Same 4-step wizard. → **FRICTION**: Sam must re-authenticate GitHub OAuth even though the token was already granted. The OAuth state is per-session and the previous token was stored only for the first product.
3. **Audit runs** → Synchronous wait again. ~45 seconds. → Sam sighs.
4. **Redirected to `/dashboard`** → Shows Company A (cookie still set). Sam switches to Company B via dropdown. Signal: 63.
5. **Sam navigates to `/portfolio`** → Investor-Ready tier passes the gate. Portfolio view loads: two cards, sorted by lowest Signal first (Company B: 63, Company A: 71). Each card is a button that switches to that product's dashboard.
6. **Sam examines the portfolio view** → Cards show: Signal number, product name, and one sentence from the Signal prose. → "Where's the MRR? Where's the risk state indicator? I can see the Signal numbers but I need to know revenue and risk at a glance."
7. **Sam clicks Company B's card** → Submits a form to `/switch-product`, sets the cookie, redirects to the dashboard. → Full page reload. Dashboard loads for Company B.
8. **Sam navigates back to `/portfolio`** → Another full page reload. → "Every navigation is a full page load. I have to go back and forth between portfolio and individual dashboards."

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **NO** — Sam is careful and checks the breadcrumb/product name. But the portfolio view is thin enough that it doesn't provide the triage value Sam expects.

## Friction Events
- FRICTION-0032: HIGH — Portfolio view shows only Signal score and a prose snippet. No MRR, no risk state badge, no stressor count, no pending decisions, no last-updated timestamp. Sam's trigger #1: "Dashboard data is stale" and trigger #2: "Cross-company comparisons use different baselines."
- FRICTION-0033: MEDIUM — GitHub re-authentication required for each new product's onboarding. The first product's GitHub token is stored encrypted per-product, not shared. Sam will need to OAuth 4 more times.
- FRICTION-0034: MEDIUM — Portfolio → product navigation is a form POST + redirect + full page reload. No client-side routing. For 5 products, this means 10+ page loads per triage session.
- FRICTION-0035: LOW — No way to add a product directly from the portfolio view. Must go to Settings → Add Product → Onboarding.

## Verdict: SUCCESS — both products visible in portfolio, but fleet view is minimal
## Would Recommend: Not Yet — "I need the fleet view to be a triage tool, not a gallery of pretty charts."
