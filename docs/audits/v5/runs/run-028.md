## Step-by-Step Transcript

1. Alex logs in. Navigates to Settings (`/settings`).
2. Settings page loads. Alex sees the Subscription card: "Current Plan: Solo" with a badge.
3. Below the badge: "You have access to N features." The number comes from `getTierCapabilities` — Solo gets 5 features (audit, dashboard, decisions, lifecycle, digest).
4. Upgrade buttons shown: "Upgrade to Investor Ready" button. **No Growth option shown.** The code at line 87-89 checks `founder.tier !== 'investor_ready'` and only shows the Investor-Ready upgrade. The Growth tier upgrade button is only shown when `!founder.tier` (no plan).
5. **FRICTION**: Alex is on Solo but cannot see a path to upgrade to Growth. The only visible option is Investor-Ready ($399) — a 5x price jump from $79.
6. Alex clicks "Manage Subscription" (visible because `founder.stripe_customer_id` exists). This redirects to the Stripe customer portal.
7. Stripe portal loads. Alex can see invoices, cancel subscription, and potentially change plans — but only if Stripe is configured with the right product catalog.
8. Alex returns to Settings.
9. Alex looks for per-company pricing breakdown. **None exists.** The Settings page shows tier name and feature count but no pricing details, no next billing date, no usage information.
10. Alex checks the Products section: "You have 1 product(s) connected." Shows product name with a "View" link.
11. Alex clicks "+ Add Product" which redirects to `/onboarding`. But Alex is on Solo tier — the `multi_product` feature gate would block adding a second product at the portfolio level.
12. Alex navigates to `/onboarding`. The onboarding flow starts for a new product. **The tier gate check happens at the portfolio view, not at product creation.** Alex could potentially create a second product but would be blocked from viewing the portfolio.
13. **FRICTION**: No pricing simulator. Alex cannot see how the price would change if they added more companies or changed tiers.
14. Alex navigates back to Settings. No invoice download link is visible. Only "Manage Subscription" which routes to Stripe.

## Cross-Company Awareness Check

- **Single product**: Product switcher shows only one product.
- **Settings page**: Shows all products for the founder but settings are not product-specific (subscription is founder-level, not product-level).
- **No confusion**: But billing model is opaque — it is unclear whether pricing is per-founder flat or per-company.

## Verdict

**FAILED**

The billing journey fails on multiple counts: (a) missing Growth tier upgrade path for Solo users, (b) no pricing transparency, (c) no proration preview, (d) no invoice access within the app. Alex cannot understand what they pay or how to change it without leaving Foundry for the Stripe portal.

## Recommendation

1. Show all tier upgrade options (Solo -> Growth, Solo -> Investor-Ready) in the Subscription card.
2. Display next billing date, current monthly cost, and per-company breakdown on the Settings page.
3. Add a tier comparison modal showing feature differences and pricing at different fleet sizes.
4. Warn Solo users attempting to add a second product that they need to upgrade first.
