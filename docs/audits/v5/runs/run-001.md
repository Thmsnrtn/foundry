## Conditions
Fleet size: 0 → 1
Tier: Solo ($79)
Device: Laptop, Chrome

## Step-by-Step

1. **Alex lands on foundry.so** → Sees hero: "Connect your product. Get a company." with 12 agent cards (Atlas, Compass, Prism, etc.) and a "How It Works" 4-step explainer. → Alex reads the daily briefing example and thinks "okay, this is specific enough to be interesting."
2. **Clicks "Give my product a team →"** → Redirects to `/auth/signup`. Clerk sign-up widget loads. Alex chooses GitHub OAuth. → Smooth. Familiar flow.
3. **Post-auth redirect to `/dashboard`** → No products exist, so immediately redirects to `/onboarding`. → Alex sees 4-step progress bar: Connect GitHub (1) → Select Repository (2) → Identify Competitors (3) → First Audit (4). Current step: Connect GitHub.
4. **Clicks "Connect GitHub →"** → GitHub OAuth flow. Alex grants repo access to the property-management-accounting repo. → Returns to `/onboarding/github/callback` showing repo list.
5. **Selects repo from dropdown** → Form posts to `/onboarding/select-repo`. Product record created. SCP provisioning fires (`ensureProvisioned`). → Redirects to `/onboarding/competitors?product_id=xxx`.
6. **Competitor identification page** → Alex enters 2 competitors (Buildium, AppFolio). Submits. → Redirects to `/onboarding/audit?product_id=xxx`.
7. **Audit page shows "Running Audit" UI** → Alex clicks to trigger the audit (`/onboarding/run-audit`). The 8-step audit pipeline runs synchronously. → **FRICTION**: No progress feedback during audit. The page hangs while `runAudit()` executes. Alex stares at a spinner or blank screen for 30-90 seconds. No streaming, no progress steps shown.
8. **Audit completes** → Redirects to `/dashboard?tour=1`. Dashboard loads with Signal score (e.g., 67), sparkline, prose summary, and a CEO briefing card referencing the actual repo. → Alex sees "Ask anything about your business..." query bar.
9. **Alex taps the Signal number** → Anatomy dialog opens showing: Base 85, stressor penalties, MRR health, decision backlog, lifecycle bonus. → "Okay, this is transparent. I can see how the number is built."
10. **Alex clicks "Agent Roster →"** from briefing card → Sees 12 agents with status dots, lifecycle badges (Setup/Learning), success rates, authority levels. → "These are real agents with version histories. Not a chatbot wrapper."
