# Run 021 — Morgan (Skeptical AI Expert) on Journey 01 (Landing to First SCP)

## Conditions
Fleet size: 0 → 1
Tier: Solo ($79)
Device: MacBook Pro, Chrome, DevTools open
Network: Fast broadband

## Step-by-Step

1. **Morgan lands on foundry.so** → Reads the landing page with a critical eye. "Sovereign Company Protocol" — Morgan googles the term. No external references. It's Foundry's own branding. → Notes: proprietary terminology, not an industry standard.
2. **Morgan reads the agent descriptions** → "Atlas CTO: Code quality, architecture, technical debt." → "What model powers Atlas? What's the prompt? What data does it see?" Marketing page doesn't say. Just names and vague domains.
3. **Morgan clicks "See pricing"** → Solo $79. Includes "12 AI agents, CEO briefings, evolution engine." → "What's the AI cost per agent cycle? Is $79 covering the inference cost or am I subsidizing other users?" No cost transparency on pricing page.
4. **Morgan signs up** → GitHub OAuth. Fast. → Onboarding wizard.
5. **Connects GitHub repo** → Morgan's own distributed-systems project. A serious codebase. Morgan wants to see how deep the analysis goes.
6. **Competitors** → Morgan enters 3 competitors with detailed positioning notes. → Submits.
7. **Audit runs** → Morgan opens DevTools Network tab while waiting. Sees a single POST to `/onboarding/run-audit` that hangs for ~50 seconds. No streaming. No WebSocket. One monolithic request. → "No progress streaming? The audit is a black box."
8. **Dashboard loads** → Signal: 68. Morgan taps the Signal number. Anatomy dialog opens: Base 85, penalties, bonus. → "These are fixed formula weights. Where did 85 come from? Why is the base 85 and not 100? What's the research backing?"
9. **Morgan navigates to Agent Roster** → 12 agents listed with lifecycle states (Setup/Learning), authority levels, success rates. → "Authority levels — okay, Gate 0 through Gate 2. But who decides the gate transition criteria? Is it the same LLM that does the analysis?"
10. **Morgan finds Agent Transparency** → `/agents/transparency`. Shows per-agent: model used (Claude Opus / Sonnet), token counts (input/output), cost ($), latency, and health scores. → **This is what Morgan needed.** "They're showing me the model, the token count, and the cost. That's more than most AI tools."
11. **Morgan clicks a specific agent run** → Detail page shows: full prompt sent to the model, context injected, response received, signals generated. → "I can see the actual prompt and the actual response. This is genuine transparency."
12. **Morgan's assessment** → "The transparency layer is strong. I can audit the reasoning chain. But the Signal score formula is opaque — where did the weights come from?"

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **NO** — Single company.

## Friction Events
- FRICTION-0071: MEDIUM — Signal score base value (85) and penalty weights are hardcoded in `computeSignal()` with no explanation of how they were derived. Morgan's trigger #3: "The system claims confidence levels without showing how they were derived."
- FRICTION-0072: MEDIUM — Audit run is a black box from the user's perspective. No progress streaming, no intermediate results. Morgan watching DevTools sees one 50-second request with no visibility into the 8 analysis steps.
- FRICTION-0073: LOW — Agent Transparency page exists and is excellent, but it's buried under Agents → Transparency in the sidebar. Not prominently linked from the main dashboard or briefing.
- FRICTION-0074: LOW — Landing page doesn't mention which AI models are used. Morgan had to sign up and find the Transparency page to discover it's Claude Opus / Sonnet.

## Verdict: SUCCESS — Morgan found the transparency they needed, though it required digging
## Would Recommend: Not Yet — "The transparency layer is better than anything else I've evaluated. But I need to verify the agent outputs aren't hallucinating metrics."
