# Run 017 — Riley (15-Company Power User) on Journey 02 (Adding Second Company)

## Conditions
Fleet size: 1 → 2
Tier: Investor-Ready ($399)
Device: MacBook Pro, Arc browser
Network: Gigabit fiber

## Step-by-Step

1. **Riley opens Settings** → Sees "+ Add Product" button. Clicks it. → Redirects to `/onboarding`.
2. **Full onboarding wizard again** → GitHub OAuth (re-auth required), repo select, competitors, audit. → Riley completes it in 4 minutes. The audit wait is the bottleneck.
3. **Redirected to dashboard** → Shows Company A (cookie). Riley knows to switch. Uses the product switcher dropdown. → Selects Company B. Dashboard loads.
4. **Riley navigates to `/portfolio`** → Portfolio view shows 2 cards. Sorted by Signal. → Riley evaluates: "Two cards. No MRR, no risk indicator, no decision count. This is a toy."
5. **Riley's keyboard test** → On the portfolio page, Riley tries: j/k (nothing), arrow keys (nothing), Tab (focuses the form submit buttons inside the cards). Enter submits the form and switches to a product. → Minimal keyboard support. Only Tab+Enter works, and it's clunky because each card is a `<form>` wrapping a `<button>`.
6. **Riley switches back to portfolio** → No keyboard shortcut to return. Types `/portfolio` in URL bar. → "There's no hotkey to go back to fleet view. That's a dealbreaker at 15."
7. **Riley checks the command palette** → Cmd+K → types "portfolio" → No match. Types "fleet" → No match. Types "companies" → No match. → Portfolio is not listed in the command palette routes at all.

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **NO** — Riley is technically sophisticated and tracks context. But Riley notes the product switcher is the only indicator of current product context, and it's small text in the header.

## Friction Events
- FRICTION-0051: CRITICAL — Portfolio/fleet view is NOT in the command palette (Cmd+K). The `CMD_ROUTES` array in layout.ts doesn't include `/portfolio`. Riley's primary navigation tool is the command palette. This route is invisible to keyboard users.
- FRICTION-0052: HIGH — No keyboard shortcuts on portfolio view. No j/k navigation between company cards. No keyboard way to return to fleet view from product context.
- FRICTION-0053: HIGH — Re-authentication with GitHub required for each new product onboarding. At 15 companies, that's 15 OAuth round-trips.
- FRICTION-0054: MEDIUM — Portfolio cards are `<form>` elements wrapping `<button>` elements. The Tab order is functional but not labeled for screen readers or keyboard users.

## Verdict: SUCCESS (technically) but the fleet mechanics are insufficient for Riley's workflow
## Would Recommend: No — "Don't make me click into each company to see its status."
