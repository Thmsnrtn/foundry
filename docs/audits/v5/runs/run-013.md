# Run 013 — Sam (5-Company Portfolio) on Journey 03 (Scaling to 15)

## Conditions
Fleet size: 5 → blocked by pricing page claim
Tier: Investor-Ready ($399)
Device: MacBook Pro, Firefox
Network: Office broadband

## Step-by-Step

1. **Sam has 5 companies in Foundry** → All onboarded over the past week. Each required separate GitHub OAuth, separate audit wait, separate competitor entry. Total onboarding time for 5 products: ~40 minutes.
2. **Sam opens `/portfolio`** → 5 cards sorted by Signal: Company E (41), Company D (56), Company B (63), Company C (69), Company A (71). → Sam can see which is worst but nothing else. No MRR. No risk state color. No pending decision count per card.
3. **Sam considers adding more companies** → The pricing page says "Up to 5 companies" for Investor-Ready. But the code has no limit — `isUnlimited = true` for investor_ready tier. → Sam doesn't try because the marketing says 5 max.
4. **Even if Sam tried to add a 6th** → The code would allow it (Investor-Ready has `Infinity` limit). But Sam trusts the pricing page. → The pricing page is lying or the code is wrong. Either way, Sam won't test the boundary.
5. **Sam evaluates the 5-company portfolio view** → No sorting controls. Sorted by lowest Signal always. No filtering by risk state. No aggregate stats (total MRR, companies in red, pending decisions). → Sam's Monday morning ritual of scanning all companies takes 25+ minutes because each requires clicking in, reading briefing, checking decisions, clicking back.
6. **Sam tries Cmd+K** → Command palette opens. Routes listed are all single-product scoped (Dashboard, Decisions, Briefing, etc.). No "Fleet overview", "All decisions", or "Compare companies" option. → Useful for navigating within a product but useless for fleet triage.
7. **Sam requests an export for board presentation** → No fleet-level export exists. Board packet generation is product-scoped (`/board`). Sam would need to generate 5 separate board packets and combine them manually.

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **YES** — At 5 companies, the product switcher dropdown contains 5 entries. After clicking into Company D from portfolio, then navigating to Decisions and resolving one, Sam wants to go back to portfolio but the browser back button goes to the Decision detail (Chamber mode, no sidebar). Sam hits back twice, lands on Company D's dashboard, and clicks portfolio from... wait, there's no portfolio link in the sidebar. Sam types `/portfolio` manually.

## Friction Events
- FRICTION-0036: CRITICAL — No link to portfolio in the sidebar navigation. The sidebar is product-scoped. The only way to reach `/portfolio` is to type the URL, use Cmd+K (which also doesn't list it), or have no product cookie set. After drilling into a company, there's no "back to fleet" navigation.
- FRICTION-0037: HIGH — Portfolio view has zero fleet-level aggregates. No total MRR, no companies-in-red count, no total pending decisions. Sam's trigger #3: "Cannot export fleet-level data for board presentations."
- FRICTION-0038: HIGH — Pricing page says "Up to 5 companies" but code allows unlimited. This false ceiling prevents Sam from testing scale beyond 5.
- FRICTION-0039: MEDIUM — No batch operations. Cannot "approve all low-risk decisions across companies" or "dismiss all info-level signals." Each action is single-product, single-item.
- FRICTION-0040: MEDIUM — Board packet is single-product scoped. No fleet-level board packet generation.

## Verdict: FAILED — Foundry does not function as a fleet control plane at 5, let alone 15
## Would Recommend: No — "Show me the deltas since last Monday. Everything else is noise."
