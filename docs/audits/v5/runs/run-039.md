## Step-by-Step Transcript

1. Sam logs in. Portfolio view. Clicks Company A, navigates to Privacy (`/privacy`).
2. Privacy page loads. Section 3: "Your Data."
3. Sam clicks "Download JSON." Export runs for Company A.
4. File downloads: `foundry-export-2026-04-16.json`. Contains metrics, briefings, decisions, customers, agent_config.
5. **FRICTION**: Sam has 5 companies and needs a complete export for investor due diligence. Must repeat this 5 times.
6. Sam navigates back to portfolio. Clicks Company B. Navigates to Privacy. Downloads JSON.
7. Repeats for Company C, D, E. Total: 5 separate downloads, 5 separate JSON files, 5 navigation round-trips.
8. **Each export takes 2-4 seconds** (5 parallel DB queries per product). Total time for 5 exports: ~3 minutes including navigation.
9. Sam now has 5 JSON files all named `foundry-export-2026-04-16.json`. **Filename collision.** Browser appends (1), (2), etc., but Sam must rename them to know which is which.
10. Sam opens the files. Each has `product_id` and `product_name` in the header. But all share the same filename.
11. **FRICTION**: No founder-level export. Sam expected one export with all company data organized by company.
12. **FRICTION**: Exports are incomplete — missing stressor_history, audit_scores, lifecycle_state, competitive_signals, product_dna (5/15+ tables).
13. Sam needs this for board presentation prep. The export format (raw JSON with database column names) would need significant processing to be useful.
14. Sam checks the GDPR job in the API. The `/api/founder-ops/export` endpoint exists but is locked to the founder email (`thmsnrtn@gmail.com`). Sam cannot access it.
15. Sam considers using the data export request mechanism. The `data_export_requests` table exists but no UI creates a record in it. The GDPR export job watches this table but Sam has no way to queue a request.

## Verdict

**FAILED**

A portfolio operator exporting 5 companies gets 5 incomplete JSON files with duplicate filenames. The export is partial (missing 10+ data categories), per-product only (no batch), and has no manifest or schema. Fails GDPR adequacy requirements for a comprehensive data export.

## Recommendation

1. Add a "Export All Companies" button that creates a ZIP archive with per-company directories.
2. Include the product name in the filename: `foundry-export-CompanyA-2026-04-16.json`.
3. Wire the privacy page to the `data_export_requests` table and GDPR export job for comprehensive exports.
4. Add a manifest file listing all included/excluded data categories.
5. For large exports (5+ companies, 3+ months data), queue the job and notify via email when ready.
