# Run 094 — Devon (P09) x Compliance Export (J09)

**Persona:** Devon — blind founder, screen reader + keyboard user, Growth tier, 3 companies
**Journey:** Compliance export (GDPR-style)
**Severity Baseline:** Devon needs to export data for all 3 companies. The process must be operable via keyboard.

---

## Simulation Transcript

### Step 1: Devon navigates to Privacy & Data

Devon uses VoiceOver to reach `/privacy`. The page has proper heading structure:
- "Privacy & Data, heading level 1"
- "Data Sharing & Consent, heading level 2"
- "Data Residency, heading level 2"
- "Your Data, heading level 2"

Good heading hierarchy within the privacy page.

### Step 2: Devon finds the Export section

VoiceOver reads the "Your Data" section:
- "Export All Data" heading
- Description text about JSON format
- "Download JSON, link"

Devon activates the link. The browser downloads a JSON file.

**Accessibility of the download process:** The `<a href="/privacy/export">` is a standard link. VoiceOver announces "Download JSON, link." No issue with activation. The file downloads to the system download location.

### Step 3: Devon examines the exported JSON

Devon opens the JSON file with a text editor or JSON viewer. The data is structured as nested objects and arrays. This is machine-readable but requires a JSON-capable tool.

For Devon using a screen reader, navigating raw JSON is tedious but possible. A CSV format would be more accessible for spreadsheet analysis with screen reader support.

### Step 4: Devon needs to export all 3 companies

Devon must:
1. Select Company 1 in the product switcher
2. Navigate to `/privacy`
3. Click "Download JSON"
4. Select Company 2 in the product switcher (which triggers page reload — accessibility issue from Run 091)
5. Navigate to `/privacy` again
6. Click "Download JSON" again
7. Repeat for Company 3

This is 3 separate exports, each requiring navigation back to the privacy page and product switching.

**Product switcher accessibility issue:** The `<select>` auto-submit causes page reloads when Devon navigates options with arrow keys. Devon must be very precise — select the option, then wait for the reload, then navigate back to privacy.

### Step 5: Devon checks the consent toggles for accessibility

Each consent toggle is a custom `<label class="toggle-switch">` wrapping a checkbox input. The checkbox has `onchange="this.closest('form').submit()"` which auto-submits.

**Accessibility issues with consent toggles:**
1. The checkbox input has `style="opacity:0;width:0;height:0;position:absolute;"` — it is visually hidden but present in the DOM. VoiceOver can focus it. Good.
2. The checkbox `id` is set (`toggle-${name}`) and the label `for` attribute matches. Good.
3. When Devon checks/unchecks, the form auto-submits (page reload). The `role="alert"` success banner announces "Settings saved successfully." Good feedback.
4. However, the toggle visual state (green track vs. dark track) is the only confirmation. No text "Enabled" / "Disabled" adjacent to the toggle. Screen readers announce "checkbox, checked" or "checkbox, not checked" which is sufficient.

**Overall assessment:** The consent toggles are reasonably accessible, with the auto-submit page reload being the main friction point.

### Step 6: Devon evaluates data residency controls

The region, retention, and log retention are `<select>` elements with associated `<label>` elements. These are standard form controls — fully accessible via screen reader and keyboard.

## Findings

| # | Severity | Finding |
|---|----------|---------|
| 1 | HIGH | **Export is per-product, requiring 3 separate downloads.** For Devon, each download requires product switching (auto-submit issue) and re-navigation. Triple the effort for 3 companies. |
| 2 | HIGH | **No CSV format.** Devon's assistive technology works better with tabular data (CSV in a spreadsheet) than with nested JSON. |
| 3 | HIGH | **Export is incomplete** (same as Run 079). Missing agent activity logs and other critical data. |
| 4 | MEDIUM | **Consent toggles are reasonably accessible.** Checkbox pattern with associated labels works with VoiceOver. Auto-submit causes page reloads but provides audible feedback. |
| 5 | MEDIUM | **Data residency controls are accessible.** Standard `<select>` elements with `<label>` associations. |
| 6 | LOW | **JSON is harder to navigate with screen reader than CSV.** Nested object structure requires more effort to understand spatially. |

## Cross-Company Awareness Check

Devon exports each company individually. No cross-company data leakage in exports — each export is scoped to `productId`. Good isolation. But no bulk "export all my companies" means Devon does 3x the work.

## Verdict: JOURNEY PARTIAL — Export works and is accessible, but is incomplete and scales poorly for multi-company users
