# Run 092 — Devon (P09) x Company Retirement (J07)

**Persona:** Devon — blind founder, screen reader + keyboard user, Growth tier, 3 companies
**Journey:** Company retirement / archival
**Severity Baseline:** Devon runs 3 profitable companies. Retiring one should be doable without seeing a pixel.

---

## Simulation Transcript

### Step 1: Devon navigates to settings to retire a company

Devon uses VoiceOver to navigate `/settings`. The settings page structure is:
- Heading: "Settings"
- Settings form (settingsPage component)
- Subscription card
- Products card (lists 3 products)
- Wisdom Network card
- Investor/Advisor Access card
- Metric Ingest card

Devon tabs through the products list. Each product has a name, optional GitHub URL, and a "View" link. No "Retire," "Archive," or "Remove" option per product.

### Step 2: Devon checks the product status controls

Devon navigates to each product's audit page via the "View" link. No lifecycle controls exist on the product detail pages either.

### Step 3: Devon checks privacy page for per-product deletion

Devon navigates to `/privacy`. This page operates on the currently-selected product. Devon can:
1. Switch to the product they want to retire (via product switcher)
2. Use "Delete My Data" to schedule deletion

But this is deletion, not retirement. Same gap as Run 077.

### Step 4: Devon encounters the delete modal accessibility

The delete confirmation modal on the privacy page uses `<div id="delete-modal" style="display:none;...">` — a custom modal, not a `<dialog>` element.

**Accessibility issues with the delete modal:**
1. **No focus trap.** When the modal opens, focus is not moved to the modal. Devon continues tabbing through background elements.
2. **No `role="dialog"` or `aria-modal="true"`.** The modal is a styled `<div>`. Screen readers do not announce it as a dialog.
3. **No Escape-to-close.** Only the "Cancel" button closes the modal. No keyboard shortcut.
4. **Background content remains interactive.** Tab key navigates to elements behind the modal overlay.

**Contrast:** The Signal Anatomy dialog on the dashboard uses the native `<dialog>` element with proper `aria-label` and close button. The delete modal does not follow this pattern.

**Codebase evidence:** `src/routes/dashboard/privacy.ts` lines 291-310 — the delete modal is a raw `<div>` with `display:none/flex` toggle. No ARIA attributes. Compare to `src/routes/dashboard/index.ts` line 75 which uses `<dialog>`.

### Step 5: Devon's screen reader experience with the risk state card

Devon has 3 companies at different risk states. The risk state card has `role="status"` and `aria-label="Risk state: Green"`. This is good — the risk state is announced as text, not just color.

**Codebase evidence:** `src/views/components.ts` line 33 — `role="status" aria-label="Risk state: ${stateLabel}"`.

However, health score visualizations on the agents page communicate scores through color-coded bars without text alternatives. Devon cannot assess agent health without text equivalents.

## Findings

| # | Severity | Finding |
|---|----------|---------|
| 1 | CRITICAL | **No retirement flow** (same as Run 077). |
| 2 | CRITICAL | **Delete modal is inaccessible.** No `role="dialog"`, no focus trap, no `aria-modal`, no Escape-to-close. Devon cannot safely interact with the most destructive action in the product. |
| 3 | HIGH | **Inconsistent dialog patterns.** The Signal Anatomy dialog uses native `<dialog>` (accessible). The delete confirmation uses a styled `<div>` (inaccessible). Two different patterns in the same product. |
| 4 | MEDIUM | **Risk state card is accessible.** `role="status"` and text `aria-label` provide screen reader support. Good. |
| 5 | HIGH | **Agent health scores lack text alternatives.** Color-coded health bars do not have `aria-label` or text equivalents. Devon cannot assess which agents are healthy and which need attention. |

## Cross-Company Awareness Check

Devon has 3 companies. Each is fully isolated. Retiring one would not affect the others. But the retirement flow does not exist, so the test is moot.

## Verdict: JOURNEY FAILED — No retirement flow, and the deletion alternative is inaccessible to screen reader users
