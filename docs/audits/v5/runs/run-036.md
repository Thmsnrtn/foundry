## Step-by-Step Transcript

1. Sam logs in. Has 5 products. No cookie set -> redirects to `/portfolio`.
2. Portfolio route: `requireTier('multi_product')` passes (Investor-Ready). `getProductsByOwner` returns 5 products.
3. `computeSignal` runs for all 5 products in parallel. On NET-AVG with 80ms latency and 5 DB queries each, this takes ~2-3 seconds.
4. Portfolio page renders: "YOUR BUSINESSES" header, grid of 5 portfolio cards sorted by Signal score (lowest first).
5. Each card shows: Signal number, product name, first sentence of Signal prose. Cards have `tier-green/yellow/red` class based on Signal tier.
6. **Sam's first goal**: Look for cross-company intelligence. The portfolio view is a grid of individual Signal scores. No cross-company insights section.
7. Sam scans for a "Fleet Intelligence" link or section. **None exists on the portfolio page.**
8. Sam clicks into Company C (middle Signal score). Cookie set, dashboard loads for Company C.
9. Sam navigates to Insights (`/products/{id}/insights`). This shows per-company revenue forecast, churn risk, peer benchmarks.
10. **Benchmarks section**: "How your metrics compare against anonymized peers on the Foundry platform." This compares against ALL Foundry users, not Sam's other companies specifically.
11. Sam wants: "Show me patterns across MY 5 companies." No such feature exists.
12. Sam navigates to the portfolio route's investment layer features. Checks `/investors` route.
13. **Investor Layer**: Board packet generation, funding readiness — these are per-product. No cross-portfolio analysis.
14. Sam checks `/products/{id}/patterns` (Judgment Patterns). These are per-product patterns from the Wisdom Layer. Not cross-company.
15. Sam navigates back to portfolio. Mentally compares Signal scores: Company A=78, B=65, C=52, D=71, E=45.
16. **The portfolio view IS the cross-company intelligence** — but it is just a sorted list of scores. No correlation analysis, no common stressor detection, no MRR comovement, no shared risk patterns.
17. Sam checks `decision_patterns` service — this generates anonymized cross-product learning patterns but the `hasConsent` check requires `cross_company_patterns` consent per product, which defaults to `false` in `getOrInitConsents`.
18. **FRICTION**: Cross-company patterns are opt-in but the default is off. Sam has never been prompted to enable them. Even if enabled, the patterns are anonymized and global — not Sam's own companies.
19. Sam checks the Wisdom Network toggle in Settings. This is a different feature (global wisdom sharing). Not cross-company intelligence for Sam's own portfolio.
20. Sam's Monday morning ritual: compare all 5 companies. Must click into each one individually, note metrics, click back to portfolio, click into the next. O(n) navigation.
21. **No batch view**: Cannot see MRR, churn, stressor counts for all 5 companies on one screen.
22. Sam concludes: cross-company intelligence is aspirational, not implemented.

## Cross-Company Awareness Check

- **Portfolio view**: Correctly shows all 5 companies with Signal scores. Product names and scores are visible. No confusion about which company is which.
- **Product switching**: Works correctly via portfolio card clicks (POST to /switch-product).
- **Data isolation**: Each product's data is correctly scoped by `product_id` in all queries.
- **Missing**: No actual cross-company intelligence — just individual products shown side-by-side.

## Verdict

**FAILED**

Cross-company intelligence does not exist as a feature. The portfolio view is a product gallery, not an intelligence dashboard. Sam cannot identify cross-company patterns, correlations, or risks without manually clicking into each product. The core value proposition of J06 — insights that are only visible across multiple SCP instances — is entirely absent.

## Recommendation

1. Build a fleet intelligence panel on the portfolio page: total MRR, MRR delta by company, common stressors, correlated risk states.
2. Add a "Fleet Signals" section that surfaces insights like "3 of 5 companies saw churn increase this week — common factor: pricing page conversion dropped."
3. Add a fleet-level MRR chart overlaying all companies on the same axis.
4. Auto-enable cross-company patterns consent for the founder's own products (distinct from the global wisdom network).
