# Run 008 — Jamie (Two-Product Founder) on Journey 03 (Scaling to 15)

## Conditions
Fleet size: 2 → blocked at 3
Tier: Growth ($199)
Device: iPad, Safari
Network: Home Wi-Fi

## Step-by-Step

1. **Jamie logs in** → Has 2 products. Uses product switcher dropdown to toggle between them.
2. **Jamie considers adding a third product** → Goes to Settings → "+ Add Product" → Onboarding wizard → adds product. → Success. Growth allows 3.
3. **Jamie tries to add a fourth** → Onboarding → selects repo or enters URL → "Product limit reached. Upgrade to Investor-Ready for unlimited products." → Blocked.
4. **Jamie checks the price** → Investor-Ready is $399/mo. Jamie is paying $199/mo. That's a $200/mo jump for the ability to add more products. → "I'm making $8K MRR across two products. $399/mo is 5% of my revenue for a dashboard."
5. **Jamie does not upgrade** → Even if Jamie did upgrade to Investor-Ready, the portfolio view only shows Signal scores as cards sorted by lowest first. There's no filtering, no sorting controls, no batch operations, and no fleet-level aggregates (total MRR, etc.). For 15 companies, this would be a flat unsorted card grid.
6. **Journey 03 is structurally impossible for Jamie** → Growth tier caps at 3 products. Even with an upgrade, the UI has no features designed for 10+ companies.

## Cross-Company Awareness
Did the user get confused about which company they were acting on? **YES** — With 3 products and only a dropdown switcher, Jamie occasionally makes decisions on the wrong product. The sidebar, Signal score, and all content change when switching, but the transition is a full page reload with no visual "you switched" confirmation.

## Friction Events
- FRICTION-0019: CRITICAL — Growth tier ($199) caps at 3 products. Scaling to 15 requires Investor-Ready ($399). No intermediate tier exists.
- FRICTION-0020: HIGH — Even on Investor-Ready, the portfolio view lacks: sorting controls, filtering, search, MRR aggregates, batch actions, keyboard navigation. It's a card grid with Signal scores and a one-line status. At 15 cards, this is unusable.
- FRICTION-0021: MEDIUM — Product switcher dropdown with 3+ items on iPad Safari opens the native picker, which shows product names but no health indicators. Jamie must remember which product needs attention.

## Verdict: FAILED — tier and UI prevent scaling beyond 3
## Would Recommend: No — "I can barely manage 3 products in this thing. 15 is a fantasy."
